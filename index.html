Formula: total XP for level L = 1,000 × (L − 1)². Spreadsheet XP model: min(event skill, 2 × show level) events per show × (horse title multiplier + optional placing bonus). Each show is credited to the horse's level when that show begins. If one show jumps multiple levels, intermediate levels correctly show 0 shows. The placing bonus is an assumption per event, not a guaranteed result; change it to match your expected placing. Title multiplier is held constant for the schedule. If the horse earns a new title, recalculate with the new multiplier.
